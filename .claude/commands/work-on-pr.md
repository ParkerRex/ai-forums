# Review Pull Request

## Instructions

1. Fetch PR details: `gh pr view $ARGUMENTS`
2. Check out the PR locally: `gh pr checkout $ARGUMENTS`
3. Review the changes focusing on:
   - Code quality and style
   - Test coverage
   - Performance implications
   - Security considerations
   - Documentation updates
4. Run the test suite
5. Provide detailed feedback with specific suggestions
6. If changes needed, comment on the PR
7. If approved, give approval status

## Review Focus

Review in the style of a senior developer focusing on:
- SOLID principles
- Clean code practices
- Potential edge cases
- Maintainability
