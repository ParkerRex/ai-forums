# Task Plan: Add Pagination to Show More Than 20 Posts

## Issue #136
**Title**: [Feature] Add pagination to show more than 20 posts
**Submitted by**: Deividas Paulauskas (david@uhostx.com)

## Problem
Currently, the post list is hardcoded to show only 20 posts at any given time. Users cannot see older posts beyond this limit.

## Analysis
After analyzing the codebase:
- The limit of 20 posts is hardcoded in `components/posts/post-list.tsx` (line 24)
- The `getPosts` query in `convex/posts.ts` accepts a limit parameter but doesn't use Convex's pagination
- The app already has a working pagination pattern in the member profile page that can be adapted

## Solution Approach
Implement cursor-based pagination with a "Load More" button, following the existing pattern from the member profile page.

## Implementation Tasks

### 1. Update Convex Query for Pagination
- [ ] Modify `convex/posts.ts` to create a new `getPostsPaginated` query
- [ ] Add `paginationOptsValidator` to the query arguments
- [ ] Replace `.take(limit)` with `.paginate(paginationOpts)`
- [ ] Maintain existing filtering and sorting logic

### 2. Update PostList Component
- [ ] Import `usePaginatedQuery` from "convex/react"
- [ ] Replace `useQuery` with `usePaginatedQuery` for the new paginated query
- [ ] Add state management for pagination cursor
- [ ] Update the posts mapping to handle paginated results

### 3. Add Load More UI
- [ ] Create a "Load More" button component at the bottom of the post list
- [ ] Show loading state while fetching more posts
- [ ] Handle "no more posts" state appropriately
- [ ] Consider auto-load on scroll as an enhancement

### 4. Maintain Backward Compatibility
- [ ] Keep the original `getPosts` query for other uses
- [ ] Ensure pinned posts logic still works correctly

### 5. Testing
- [ ] Test with various post counts (< 20, exactly 20, > 20)
- [ ] Test "Load More" functionality

- [ ] Check performance with large datasets

## Technical Details
- Use Convex's built-in pagination helpers
- Follow the pattern from `app/members/[slug]/page.tsx`
- Default page size: 20 posts (configurable)
- Consider implementing infinite scroll in a future iteration

## Success Criteria
- Users can see all posts, not just the first 20
- Smooth loading experience with "Load More" button
- No regression in existing functionality
- Performance remains acceptable
